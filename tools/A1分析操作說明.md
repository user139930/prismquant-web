# A1 新聞分析 — 完整操作說明

這份文件教你怎麼**跑 A1 新聞的情緒/主題分析**，以及**怎麼省錢、怎麼換模型**。

---

## 一、先懂一件事：分析在哪裡跑

- **分析是在 `news-main`（A1 的 Streamlit 專案）跑的**，不是在前端。
- 跑完後，用 `tools/export.py` 導出成 `data/news.json`，前端只是「顯示」這個快照。
- 所以「換模型」是在 **news-main 的 `.env` 或網頁介面** 改，不是在前端改。

---

## 二、省錢原則（重要）

分析用 **OpenRouter**（一個 key 用很多家模型），按量計費。**一定要用 flash 類模型**，別用 pro/推理模型：

| 模型 | 成本 | 建議 |
|---|---|---|
| `deepseek/deepseek-v4.1-flash` | ★ 最便宜 | **預設，就用這個** |
| `deepseek/deepseek-v4-pro` | ★★ 貴幾倍 | ❌ 是推理模型，輸出會失敗 |
| `openai/gpt-*` / `anthropic/claude-*` | ★★★ 貴 10-50 倍 | ❌ 分析新聞不需要 |

**190 條新聞全部分析完，用 flash 大概只要幾塊錢港幣。** 不用擔心「跑著跑著沒錢」。

> 為什麼不能用 `deepseek-v4-pro`：它是「推理型」模型，會先把思考過程放進一個
> `reasoning` 欄位、真正的答案 `content` 是空的，導致 A1 解析失敗。
> flash 版直接輸出答案，又便宜又快。

---

## 三、兩種跑法

### 方法 A：命令列（推薦，適合批量）

```bash
# 1. 進入 news-main 資料夾
cd <news-main 資料夾>

# 2. 建 .env（用 OpenRouter key，模型用 flash）
#    把下面幾行存成 .env（key 換成你自己的）：
OPENAI_API_KEY=sk-or-v1-你的key
OPENAI_BASE_URL=https://openrouter.ai/api/v1
LLM_MODEL=deepseek/deepseek-v4.1-flash
LLM_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-v1-你的key

# 3. 跑分析（--analysis-only 只分析不重新抓新聞）
.venv\Scripts\python.exe -m src.rss_pipeline --analysis-only --analysis-limit 100

# 4. 導出成快照（--analyzed-only 只取已分析的）
<前端路徑>\tools\... python tools/export.py news \
    --db "data/news.sqlite3" --limit 30 --per-source 3 --analyzed-only \
    --out <前端路徑>\data\news.json
```

> 注意：第 3 步用 **news-main 自己的 venv**（`.venv\Scripts\python.exe`），
> 第 4 步用**任何 Python** 都行（export.py 零依賴）。

### 方法 B：網頁介面（有模型選擇下拉選單）

```bash
cd <news-main 資料夾>
.venv\Scripts\python.exe -m streamlit run app.py
```

打開網頁後，左側有「**AI 服務商**」和「**AI 模型**」兩個下拉選單：

1. 「AI 服務商」選 **OpenRouter**
2. 「AI 模型」選 **`deepseek/deepseek-v4.1-flash`**（或「自訂模型 ID」自己填）
3. 貼上你的 key

這介面本來就內建，適合臨時分析單則新聞，不適合大批量。

---

## 四、換模型怎麼做

**命令列**：改 `.env` 裡的 `LLM_MODEL` 那一行，例如：

```
LLM_MODEL=google/gemini-3.8-flash     # 換 Gemini flash（OpenRouter key 也能叫）
LLM_MODEL=deepseek/deepseek-v4.1-flash  # 換回 DeepSeek flash
```

**網頁**：直接在「AI 模型」下拉選單選。

可用的模型 ID 去 OpenRouter 查：https://openrouter.ai/models

---

## 五、踩過的坑（照著避免）

1. **CLI 分析讀的是 `OPENAI_API_KEY`，不是 `OPENROUTER_API_KEY`**。
   `.env` 兩個都要設，且 `OPENAI_BASE_URL` 要指到 `https://openrouter.ai/api/v1`。
2. **別用推理模型**（deepseek-v4-pro 等），輸出會是空的。
3. **長新聞曾被 max_tokens=2000 截斷**，已改成 8192（`src/analyzer.py` 第 240 行附近）。
   如果隊友更新 news-main 把這行改回去，長新聞又會失敗，要再調大。
